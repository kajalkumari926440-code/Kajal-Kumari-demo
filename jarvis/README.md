# Jarvis - Personal AI Voice Assistant

Jarvis is my first Python project. It is a personal voice assistant designed to perform computer tasks and answer questions using AI.

## Features

- Voice input and voice responses
- Open Google and YouTube
- Play specific songs
- Answer questions using Gemini AI
- Speech recognition and text-to-speech
- Perform selected computer operations

## Technologies Used

- Python
- Google Gemini API
- SpeechRecognition
- Pyttsx3
- PyWhatKit
- Python-dotenv

## Installation

1. Install Python on your computer.
2. Install the required dependencies:

   `pip install -r requirements.txt`

3. Create a `.env` file in the project folder.
4. Add your Gemini API key to the `.env` file:

   `GEMINI_API_KEY=your_api_key_here`

5. Run the project:

   `python main.py`

## Security

Never upload your actual API key or `.env` file to GitHub.
